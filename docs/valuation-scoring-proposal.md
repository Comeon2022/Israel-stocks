# Valuation scoring proposal (not activated)

The existing /15 valuation score is hard-coded and is not production-ready. No score is activated in Phase 7H.

For review, two deterministic options are possible: (1) peer-relative percentile scoring using only same-basis compatible multiples, or (2) explicit absolute bands for P/E, EV/EBIT, and FCF yield. Both must exclude unavailable metrics, publish thresholds, and treat retailer reported and ex-IFRS16 definitions as separate populations. Missing lease cash payments must never receive an implied FCF score. A final choice requires product review; this file is not executable scoring logic.
